# fangban-ppt · 方班论文汇报 PPT 制作技能

一个面向 **方班（网络空间安全示范班）论文汇报** 的 AI Agent Skill：输入一篇学术论文和目标页数，自动完成「论文精读与批判分析 → 逐页大纲规划 → 生成可直接上台的 PPT」全流程。

## 核心理念

- **以问题研究为导向**，而非照搬论文目录顺序；先建立「问题研究链」，再做"熵减"，聚焦论文的核心创新点（文章的"核"）。
- 融合 **文献精读** 与 **科学批判思维**：不仅讲清方法与证据，还主动识别实验偏倚、统计问题、逻辑谬误与方案缺陷。
- 内置方班演讲方法论：规避 8 大常见反例，落实总分结构、系统框图、形象化对比、类比、导航条与动画。

## 目录结构

```text
fangban-ppt/
├── SKILL.md                         # 主流程：四阶段闭环
└── references/
    ├── fangban-methodology.md       # 方班演讲方法论（8大反例/口诀/呈现技巧/自查清单）
    ├── paper-analysis.md            # 论文精读 + 科学批判分析框架
    └── slide-blueprint.md           # 页面蓝图与 10/12/15/18/20 页分配方案
```

## 工作流程

1. **阶段 0 · 确认输入**：论文、目标页数（硬约束）、时长、输出载体（默认飞书幻灯片，可选本地 .pptx）。
2. **阶段 1 · 精读与批判**：产出「论文分析画布」——一句话贡献、问题研究链、核心创新点、证据对应、批判局限、对比与类比素材。
3. **阶段 2 · 规划 N 页大纲**：按蓝图把内容精确映射到指定页数，核心创新点占 40–50% 篇幅，每页含结论性标题与演讲备注。
4. **阶段 3–4 · 生成与自查交付**：逐页闭环生成 PPT，用 14 项清单核验后交付。

## 使用方式

对 Agent 说，例如：

> 用这篇论文做一份 15 页的方班 PPT（附上 PDF）；需要本地文件则补充"输出 .pptx"。

## 依赖的姊妹技能

- 文献精读：`doubao-paper-close-reading`
- 科学批判思维：`scientific-critical-thinking`
- 飞书幻灯片：`ppt`（默认生成通道）
- 本地 PPTX 生成器：`ppt-generator`（备选通道）
