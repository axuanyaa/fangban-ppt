# 论文精读与批判分析框架（阶段一）

目标：在动手做 PPT 前，先把论文"读懂、读透、读出批判"，产出可直接用于页面规划的结构化结论。融合"文献精读"七阶段与"科学批判思维"。

## 一、分析原则

- **先理解，再评价**：没搞清问题、方法、实验之前不急于挑错。
- **先给判断，再展细节**：先形成一句话核心贡献与价值判断。
- **全文看见、重点深读**：标题/摘要/引言/方法/实验/结论/图表/附录都要覆盖，但时间向决定结论的部分倾斜。
- **区分四类信息**：
  1. 论文直接报告的事实/结果；
  2. 作者对结果的解释；
  3. 分析者基于证据的推断；
  4. 材料不足、当前无法确认的事项。
- 贡献声明 ≠ 贡献证据；图表往往比正文更诚实。

## 二、七阶段分析流程

1. **明确目的与材料**：确认论文版本、可读范围（正文/图表/附录/补充材料/代码），记录论文标题、作者、 venue、年份、类型（实证/理论/系统/综述等）。
2. **建立全景**：先读标题、摘要、引言、结论、主要图表与目录，判断研究对象、重要性、作者声称的缺口与贡献、证据类型。写出**一句话核心贡献**："本文通过什么关键方法/思想，解决什么问题，取得什么主要结果"。
3. **重建研究故事与论证链**：研究问题 → 现有方法为何不够 → 核心洞察 → 方法如何回应缺口 → 哪些证据支撑 → 结论在何条件下成立。检查声称创新与实际创新是否一致、论证有无跳步。
4. **拆解方法/理论机制**：任务定义、输入输出、整体流程与核心模块、关键公式/目标函数、每个模块"为什么存在"、与已有方法的真实差别、依赖的假设与成本。
5. **深读证据与实验**：定位支撑每个主结论的图表/实验；核查数据集、基线、指标、实验条件、消融、误差/敏感性分析；关键数字与原图表核对。
6. **形成批判判断与可信边界**（结合第三节）：哪些结论被充分支持、哪些需补条件、哪些只是作者解释、哪些被过度宣称；列出作者承认的局限、分析者推断的局限、无法确认的事项。
7. **转化价值**：提炼可复用的核心洞察/模块/设计、不可直接迁移之处、后续研究问题、最小验证路径。

## 三、科学批判思维检查点

### 3.1 实验设计与效度
- 设计是否匹配研究问题，能否支撑因果断言；对照/基线是否恰当。
- 内部效度：随机化、混杂控制、选择偏倚、流失模式。
- 外部效度：样本代表性、能否推广到目标场景。
- 构念效度：测量是否真正度量目标对象。
- 统计结论效度：功效/样本量是否足够、模型假设是否满足。

### 3.2 偏倚扫描
- 研究者：确认偏倚、HARKing、发表偏倚、择优报告（cherry-picking）。
- 选择：抽样偏倚、自选择、流失偏倚、幸存者偏倚。
- 测量：观察者偏倚、回忆偏倚、社会期望偏倚。
- 分析：P-hacking、结果切换、选择性报告、亚组捕捞。
- 混杂：是否存在同时影响自变量与因变量、却未被控制的因素，是否有替代解释。

### 3.3 统计与主张
- 检验是否适配数据类型与设计；多重比较是否校正。
- 是否把 p 值误读、把统计显著当成实际重要；是否报告效应量与置信区间。
- 是否把相关当因果、局部结果过度推广、缺失数据处理是否得当。
- 主张强度是否与证据匹配：识别"prove/首次/最优"等过强表述，给出恰当的限定语。
- 主动找反例：哪些数据集/指标/亚组上没赢过基线、哪些提升微弱或不稳定、哪些负面结果被弱化。

### 3.4 逻辑谬误（出现即标注）
- 因果类：事后归因、相关即因果、因果倒置、单因谬误。
- 推广类：以偏概全、轶事证据、择优、生态谬误。
- 来源类：诉诸权威、人身攻击、起源谬误。
- 结构类：虚假二分、循环论证、稻草人、不可证伪、完美主义谬误（Nirvana）。
- 谬误只说明"该论证不成立"，不等于结论本身错误。

## 四、标准化分析产出（"论文分析画布"）

完成分析后，必须整理出以下字段，作为阶段二页面规划的唯一依据：

```text
1. 论文信息：标题 / 作者 / venue / 年份 / 论文类型
2. 一句话核心贡献（先写后校正）
3. 问题研究链：
   - 背景与意义（why，对非专家怎么讲）
   - 研究问题（清晰定义 + 边界）
   - 研究现状与缺口（最新/经典工作，各自差异）
   - 核心洞察/动机
   - 方法总览（系统框图要素）
   - 分模块机制（每模块解决什么、为什么存在）
   - 关键证据（哪张图表/实验支撑哪个创新点）
   - 结论与成立条件
4. 文章的"核"：最核心的 1–2 个创新点 + 对应难点（需讲透处）
5. 术语/缩写表：需先解释的概念
6. 批判分析：
   - 作者承认的局限
   - 分析者推断的局限/缺陷（含位置与影响）
   - 无法确认的事项
   - 过强主张与建议限定语
7. 形象化素材：可做的对比、可打的比方、可重绘的关键图
8. 结论与展望：证据能支撑到哪一步、可能的改进方向
```

> 若只有摘要/节选等不完整材料，可形成有限分析，但必须显式标注覆盖范围，不得把它当作全文精读结论，也不得编造缺失的数字、公式或实验。
