# 方班学术演讲方法论（内容与呈现规范）

本文件固化"如何作一次还不错的学术报告/演讲"的方法，是制作方班论文汇报 PPT 时必须遵守的内容与呈现标准。核心目标：**信息精炼、沟通高效、易于记忆**。

## 一、总纲：以问题研究为导向

制作 PPT 不是把论文顺序搬一遍，而是带听众走一条"问题研究链"：

```text
研究背景与意义 → 研究问题（定义清楚）→ 研究现状与缺口
→ 核心洞察/动机 → 研究方案 → 关键证据 → 结论与边界
```

在问题研究链基础上做"熵减"，把讲解火力集中到论文的**核心创新点（文章的"核"）**。不抓核心会看似面面俱到，实则难点一带而过、听众抓不住重点。

## 二、必须规避的 8 个反例（现象 → 改进）

| # | 反例现象 | 问题本质 | 必做改进 |
|---|---------|---------|---------|
| 1 | 满页文字/伪代码、照稿念 | 信息冗杂、低效、难记 | 伪代码归纳为关键步骤；大段文字提炼为关键词/短句，结构化表达；记逻辑而非背词 |
| 2 | 把听众当专家，跳过背景，直接用未解释的英文缩写 | 只讲 what/how，漏掉 why | 多举例；反问"不做行不行、不做好不好"；讲方法前先解释概念术语和缩写 |
| 3 | 相关工作介绍不清 | 难点不明、难衡量贡献；引用太老 | 讲最新工作→说清差异；讲经典工作→说清后续发展；不讲被技术博客说烂的论文 |
| 4 | 图表数据堆砌但无目标无结论 | 缺有力观点、无聚焦 | 每页只完成一个目标，结论显式标出，图表关键位置加红框/高亮 |
| 5 | 无指引、无动画地讲复杂流程/算法 | 听众跟不上 | 用动画、激光笔引导注意力；先宏观后细节；每阶段小结并回到主线 |
| 6 | 定理、公式讲不清 | 理论复杂、短时听不懂 | 用直白语言讲清原理与目的，尽量定性地讲，再给形式化 |
| 7 | 超时、埋头苦讲、语速过慢 | 放不下细节、未预讲 | 抓住主线，主线外细节不讲或少讲，提前预讲计时 |
| 8 | 时间过短、语速过快、不交流 | 细节太少、选题不当 | 关键处停顿讲透；眼神交流观察听众；选题事先请导师把关 |

### 三句口诀（贯穿全篇）
- **总体内容（反例1–3）**：文字代码别太多、背景现状别太少
- **每页讲法（反例4–6）**：有头有尾有指引、理论定性讲意义
- **控场姿态（反例7–8）**：抓住主线控时长、眼神交流多互动

## 三、四个结构性问题（决定内容组织顺序）

1. **不要完全按论文顺序**：背景之后直接抛贡献会导致现状不清、研究链断裂。应先建立问题研究链，再把论文贡献作为"特色/创新点/研究意义"介绍。
2. **先定义研究问题，再讲方案**：问题不清会造成理解跨度大。
3. **交代最新研究现状**：否则听众看不到问题全貌、缺乏必要对比。
4. **不要照搬论文观点、只讲优点**：要澄清方法的来龙去脉，主动指出相关工作对比与自身方案缺陷，并思考可能的改进（顶会顶刊也可能回避强相关工作或缺陷，需批判性补足）。

## 四、页面呈现技巧

- **总分结构 + 系统框图**：方法部分先给整体框架图，再分模块展开，前后联系、反复强化主线。
- **证据闭环**：实验数据必须能支撑创新点；方法/性能对比必须能支撑结论与展望；支撑不了的不强行宣称。
- **形象化对比**：抽象、没有对比时增加可视化对比（前后对比、有无对比、与基线对比），让人一目了然。
- **打比方（类比）**：借助听众已有知识解释新概念，先给直觉再给定义。
- **引导设计**：复杂流程用分步动画；全篇加导航条（标明当前所处环节）。
- **文字配比**：幻灯片放关键词/短句，完整解释放进演讲者备注，避免满屏文字。

## 五、交付前自查清单（逐项打勾）

- [ ] 是否建立了完整"问题研究链"，而不是照搬论文目录顺序？
- [ ] 是否用一句话说清了论文的"核"，并围绕它分配篇幅（难点讲透）？
- [ ] 背景、动机（why）、术语缩写是否对非专家听众讲清楚？
- [ ] 相关工作是否讲清差异/发展，而非简单罗列？
- [ ] 是否每页只讲一个目标，且每页结论显式可见？
- [ ] 方法是否先给系统框图（总）再分模块（分）？
- [ ] 图表是否有聚焦（红框/高亮）、有结论，数据是否真正支撑创新点？
- [ ] 复杂流程是否有动画/指引、是否先整体后局部、是否有阶段小结？
- [ ] 定理公式是否先定性讲原理目的？
- [ ] 是否有形象化对比或类比帮助理解？
- [ ] 是否有导航条、合理动画，文字与口述配比是否得当？
- [ ] 是否批判性指出方案局限/缺陷并给出改进思考？
- [ ] 页数与时长是否匹配，是否预留预讲、关键处停顿与眼神交流？
- [ ] 全篇是否无 emoji、术语统一、无未定义缩写？
